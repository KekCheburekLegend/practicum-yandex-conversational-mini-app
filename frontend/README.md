# Frontend — Chat Shell

Каркас интерфейса по задаче #15. React, TypeScript, Vite и CSS Modules.

## Запуск

Требуется Node.js 22.12+ или 24 LTS.

```sh
cd frontend
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Проверка типов и production-сборка выполняются командой `npm run build`. Просмотр сборки — `npm run preview`.

## Возможности

- Создание и переключение диалогов, отправка сообщений кнопкой или Enter. Shift + Enter добавляет строку.
- Вкладки Research Board, Project Planner и Data Explorer в едином рабочем пространстве.
- Тёмная и светлая темы, выбор акцентного цвета, адаптивная компоновка.
- Явное обозначение демонстрационного режима и места подключения mini-app.

Состояние диалогов и оформления хранится в памяти вкладки. Перезагрузка сбрасывает его. Пользователь явно выбирает приложение, после отправки отображается демонстрационный ответ. Backend API, маршрутизатор, runtime и Schema Renderer подключаются в следующих задачах. Контракты взаимодействия предстоит согласовать с командой. Платформа самостоятельная, обязательная или официальная интеграция с ChatGPT/OpenAI отсутствует.
