# Conversational Mini-App Studio
Платформа, которая превращает запрос в чате не просто в текст, но и в интерактивный, проверяемый интерфейс. Маршрутизатор выбирает нужный инструмент, runtime открывает подходящее mini-app, а пользователь меняет параметры, проверяет источники и возвращает структурированный результат обратно в диалог.

## Зачем нужна платформа
Обычный текстовый чат плохо подходит для задач, где нужно сопоставлять доказательства, двигать сроки, фильтровать данные и проверять гипотезы. Студентам, исследователям и проектным командам нужен единый разговорный вход в специализированные визуальные пространства, где ответ можно исследовать, изменить и перепроверить, а не только прочитать.
