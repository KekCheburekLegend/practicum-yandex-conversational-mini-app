# Research Board

## Задача мини-приложения
Дать пользователю визуальную доску исследования, на которой источники, утверждения (claims) и противоречия связаны между собой. Пользователь должен видеть, какие утверждения подкреплены evidence, какие остались без источника, и где источники противоречат друг другу — без ручного сопоставления и без потери контекста диалога.

## UX-примечания (где это живёт в интерфейсе)
- Индикатор «claim без evidence» — на карточке claim, не в отдельной панели; не должен занимать место на главном экране постоянно.
- Противоречия — подсветка на доске + компактный счётчик в шапке mini-app, раскрывается по действию.
- Inspect-панель (route, tool arguments, schema validation) — скрыта по умолчанию, открывается кнопкой Inspect в шапке.
- Confirmation gate — только перед удалением / массовым изменением / экспортом, а не на каждое действие.
